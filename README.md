# EF431-Industrial-Facilities-Design
Facilities Planning & Industrial Systems DesignThis repository contains mathematical models, case studies, and design principles for optimizing industrial facilities. The goal is to maximize production throughput while minimizing costs and ensuring regulatory compliance.🛠 Key FeaturesLocation Modeling: Implementation of Single-Facility Location models using Rectilinear (Median) and Euclidean (Gravity) distance methods.Layout Design: Systematic layout planning using Relationship (REL) Charts and Adjacency Graphs to optimize departmental flow.Lean Systems: Application of Just-in-Time (JIT), Little’s Law, and Takt Time to reduce Work-in-Process (WIP).Compliance & Safety: Calculations for industrial ventilation (CFM) and worker capacity based on the Factories Act.📊 Core Concepts CoveredMaterial Handling: Unit Load design and equipment selection logic ($T = P \times L$).System Design: Cellular manufacturing using the Direct Clustering Algorithm (DCA).Cost Reduction: Minimizing Total Weighted Distance for logistics and internal transport.🚀 How to UseCalculations: Use the provided templates to solve site selection and capacity problems.Analysis: Refer to the REL chart logic to evaluate existing floor plans.
